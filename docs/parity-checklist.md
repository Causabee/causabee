# One app on every device — the check before a release

Causabee is one app: the Mac, the iPhone and the iPad have the same features, the same actions under the same words, and the same data. Only the layout adapts to the screen, and only what a device physically lacks may differ. Before each release, tick each line on the **Mac** and on the **iPhone** (and the iPad where it says so). A line that differs is fixed before the release, or written down with its reason.

Words come from one list in code: `Say` in `Sources/Causabee/MatterMenus.swift`. A menu item is in Title Case, with "…" where it asks something more first.

## Data

- [ ] A mail sorted on one device shows on the other with its digest, its whole text (*Show the whole mail*) and its tasks and dates.
- [ ] A screenshot or scan taken in on one device: its card in the assistant, its file and what it said, on the other.
- [ ] Settings changed on one device are the same on the other: Auto, *Fewer, real tasks*, *The bee is glad*, calendar and list, the owner's names.
- [ ] The unread dot is the same on both after a mail check.

## A matter's page

- [ ] Header: "n mails · since …"; Tasks: "n open · m done".
- [ ] The plus (bee held / beside the assistant's field): Task, Note · Link, Detail, Contact · *Read and sorted in*: Photo or screenshot, Scan a document (Mac: Import from iPhone), File · *Kept only, not read*: Files or a folder. Task and Note open their editors.
- [ ] ⋯: Write Next Step and Summary Again (⌘R), Pin to Top / Unpin, Rename …, Icon, Merge With, Export as RTF, Open Again / Close Matter ….
- [ ] Record: Kind, Show, Sort menus; By person; links both ways (from the mail of … / chips); read and kept-only cards with Read; Choose …; Unread.
- [ ] Find searches all mail.
- [ ] A scan or a file brought in opens as the file.
- [ ] Dropping files and links onto the matter keeps them (Mac, iPad).

## The assistant

- [ ] Under an answer: Copy, Save as note, Try again, Sources, what was sent (tap the price), "read X as Y".
- [ ] 20 turns at first, "Show earlier · n more" brings 20 more.
- [ ] Reading mode hides suggestion cards; a drafted mail stays.
- [ ] A screenshot pasted (plus → Paste screenshot, ⌘V) or dropped on the assistant is read.

## The overview

- [ ] Week, overdue, *Matters with unread mail*, pinned cards, the matters, and folded *Quiet · n* and *Closed · n*.
- [ ] Every matter's card and row has the same menu: Pin to Top / Unpin, Rename …, Icon, Merge With.
